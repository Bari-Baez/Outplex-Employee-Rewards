Outplex Employee Hub API

Internal REST API for the Outplex Employee Hub platform.

Covers overtime management, company store (NYT), employee marketplace, raffles, communications, forms, breaks scheduling, and admin operations.

Authentication

Most endpoints require a valid Supabase session cookie obtained after authenticating via Slack OIDC (/auth/callback). Dev/bootstrap endpoints use a service token in the x-dev-token header.

Roles (least → most privileged)

| Role | Description | |------|-------------| | employee | Regular employee — basic access | | moderator_b1 | Supervisor — manages breaks, OT, and bath time | | moderator_a1 | Senior moderator — full moderation suite | | moderator | General moderator | | admin | Full administrative access |
